# Лабораторная работа №10: Приложение «Дневник задач» (Вариант 2)

Готовый JavaFX-проект с сериализацией данных в JSON с использованием библиотеки Jackson.

## Особенности реализации
- **Вариант №2**: Дневник задач с дополнительным полем **Приоритет** (Высокий, Средний, Низкий).
- **Демо-данные**: Встроено 10 начальных демонстрационных записей.
- **Функционал**: Добавление, удаление с подтверждением, изменение записей.
- **Поиск**: Живой поиск и фильтрация по заголовку (`FilteredList`).
- **Сохранение/Загрузка**: Атомарная перезапись файлов JSON с использованием Jackson Databind, валидация поврежденных файлов.
- **Кодировка**: Полная поддержка UTF-8.
